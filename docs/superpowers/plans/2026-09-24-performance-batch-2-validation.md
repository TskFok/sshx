SFTP 读取线程通过 macOS 的安全 `fcntl` 接口使用非阻塞 PTY。子进程结束后排空可读数据；若后代持续输出，最终排空最多追加 1 MiB 或持续 100 ms，随后关闭接收端并 join。该限制保障读取线程回收，不保证终止任意脱离会话的后代。新增的 macOS `nix 0.25.1` 直接依赖复用现有锁文件版本；未增加 unsafe 代码。

第一批输出 ready/ACK、16 KiB 输出块、256 KiB 输出窗口，以及 transferId、running/success/failed、取消与历史清理协议保持。没有引入第三批 Channel、SFTP 并发或 WebGL。

实现取舍：重排等待写入成功再刷新，去掉会被旧请求/并发失败覆盖的乐观回滚。写入已成功但刷新失败时保留失效状态，后续加载可重试，避免把成功写入误报为失败而重复创建或导入。

独立审查已完成，发现的认证日志退出竞态与文件列表焦点回抢已修复，SFTP 有界收尾专项复审通过，无未修复的重要缺陷。

## 本机结果

环境：macOS 26.5.2 / Apple Silicon，Rust 1.93.1，pnpm 10.28.2，仓库锁定依赖。功能测试使用模拟消费者、临时目录、内存 SQLite、本地 SFTP server 与合成输出，不访问用户保存的真实服务器。

- `pnpm test`：2026-09-28 最终前端回归 38 个测试文件、270 项全部通过，包含搜索和手动滚动不抢焦点的回归。
- `pnpm build`：TypeScript 和 Vite 生产构建通过，终端、文件传输及普通页面均生成独立分块。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：2026-09-28 格式化后最终回归 199 项通过、4 项按配置忽略、0 失败，无 warning。忽略项是两个手动性能采样和两个隔离 sshd 测试；后者已另外执行通过。
- `cargo test --manifest-path src-tauri/Cargo.toml isolated_ --lib -- --ignored`：两项本地隔离 sshd 主机密钥集成测试通过（2026-09-24）。沙箱内绑定回环端口受限，自动审批后在沙箱外执行，仅使用临时配置和临时密钥。
- `git diff --check`：通过。

生产预览通过 Codex 内置浏览器验证：首页资源不包含终端/文件传输分块，点击目标工作区才加载；切换到文件传输时终端 DOM 保留且隐藏。浏览器使用空库，不代表 Tauri 中真实会话及传输压力验收。
