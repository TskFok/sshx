# 私钥路径文件选择设计

## 目标

在连接表单的「私钥路径」字段上，支持通过系统文件对话框选择私钥文件，同时保留手输路径。

## 背景

密钥 / 密钥+密码认证时，私钥路径只能手输。应用保存的是路径（加密），不是密钥内容。后端会做 `~` 展开并读取该文件。项目已使用 `@tauri-apps/plugin-dialog` 的 `open()`（导入备份、壁纸、SFTP 上传）。

## 方案

连接编辑对话框中，「私钥路径」改为同一行：左侧可编辑输入框，右侧「选择文件」按钮。

- 点击按钮调用现有 `open()`：单选文件、不定扩展名过滤（`id_ed25519` 等常无后缀）、标题为「选择私钥文件」。
- 输入框已有非 `~` 开头的路径时，将其作为 `defaultPath`；空路径或以 `~` 开头时不设 `defaultPath`（系统对话框不展开 `~`）。
- 取消选择不改动当前值；选中后把返回的绝对路径写入输入框。
- 不读取、不复制私钥内容。保存、加密、认证逻辑不变。

辅助说明改为：可输入绝对路径（支持 `~` 展开），或点击选择文件。

## 测试

抽出对话框结果解析与 `defaultPath` 规则为纯函数并补单元测试：取消 / 空值 / 单路径 / 多选取第一项；空路径与 `~` 路径不带 `defaultPath`，绝对路径带 `defaultPath`。
