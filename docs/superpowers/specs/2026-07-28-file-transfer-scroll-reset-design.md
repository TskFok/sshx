# 文件传输连接详情滚动复位设计

## 目标

用户在文件传输连接列表中点击任一连接后，进入对应详情页时，内容区域始终从顶部显示。

## 根因

`MainLayout` 的滚动复位逻辑使用了 `fileTransferScrollRef`，但该 ref 被绑定到了终端容器；真正承载 `FileTransferWorkspace` 的容器没有 ref。因此路由切换时复位了错误的元素，文件传输页面保留了此前的滚动位置。

## 方案

将 `fileTransferScrollRef` 绑定到文件传输工作区的 `<main>` 容器，并从终端容器移除该绑定。继续在访问 `/file-transfer/:connectionId` 时将该容器的 `scrollTop` 设为 `0`。

不改变终端页面或文件传输标签页的持久化逻辑；连接详情之间切换时的滚动复位行为也保持现状。

## 回归测试

调整 `MainLayout` 测试桩，使终端与文件传输容器使用独立的 ref 对象。验证进入文件传输连接详情时，仅文件传输工作区容器被复位到顶部，避免两个容器共用模拟对象而掩盖绑定错误。
